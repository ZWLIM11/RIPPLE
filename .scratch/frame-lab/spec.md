# Screenshot paste and partial-frame exploration

Support clipboard image paste through the shared validated upload loader. Support known pitch rectangles with four visible landmarks: whole pitch, halves, penalty areas. Partial frames remain separate from the 22-player board to prevent unseen players being invented or saved as observations. Report geometric distance/marked opponent clearance only, never safety rankings or success rates. Include experimental local colour-component assistance with explicit human identity/feet review and no automatic application. Keep Azure optional.

All screenshots stay local unless the user explicitly invokes the existing Azure suggestion control. The earlier StatsBomb and Wyscout research models failed the practical improvement gate; this release does not promote or retrain them.

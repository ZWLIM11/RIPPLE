# Prediction studio feature set

Implement on v1zw:
- Optional Foundry tool-calling explanations constrained to verified bilingual facts,
  with server-side credentials, bounded tool calls and local fallback.
- Estimated ball/receiver/defender route animation with cancellation and reduced motion.
- Observed turning points, earlier contribution chains and player-focused recaps.
- English/Malay narration and key controls.
- Timed broadcast overlay with machine-readable evidence and export.
- Fixed-candidate defender-position sensitivity sweep.
- Better synthetic recovery/restart continuity and seeded scenario selection.
- Optional vision suggestions requiring explicit request and per-marker review.
- Model and DOM interaction tests; document outstanding empirical/visual validation.

Prediction means estimated physical feasibility/risk, not calibrated probabilities.
Synthetic simulation is not independent proof of real-world predictive accuracy.

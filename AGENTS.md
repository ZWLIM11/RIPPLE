## Agent skills

### Issue tracker

Track specs and individual tickets in local Markdown under `.scratch/<feature>/`. Before creating or updating tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the default triage role labels. Before assigning ticket readiness, read `docs/agents/triage-labels.md`.

### Domain docs

Use one root glossary and `docs/adr/`. Before exploring or changing the domain model, read `docs/agents/domain.md`.
